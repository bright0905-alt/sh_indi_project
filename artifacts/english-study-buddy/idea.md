# 영어 단어·숙어 학습 복습 웹앱

## Problem Statement
HMW — 영어 공부 중 모르는 단어/숙어의 뜻을 찾고 발음을 들은 뒤, 그 단어들을 두 방향(단어→뜻, 뜻→단어) 퀴즈로 복습하며 잊지 않게 하려면?

## Recommended Direction
순수 웹 앱으로 영어 학습이라는 핵심 가치에만 집중한다. 사전은 찾는 순간엔 유용하지만 그대로 두면 금방 잊히므로, 검색 자체를 복습 루프로 닫아주는 것이 이 앱을 단순 사전이 아니라 학습 도구로 만드는 지점이다.

핵심 기능은 5개: (1) 단어/숙어 사전 검색(뜻+예문), (2) 문장 한글 해석, (3) 단어/숙어/문장 발음(TTS), (4) 저장된 단어/숙어를 양방향(단어→뜻, 뜻→단어) 퀴즈로 복습하고 선택한 리스트를 발음+뜻으로 읽어주기, (5) 해석한 문장을 별도의 문장 노트에 저장하고 클릭 시 적용된 문법 설명을 제공. 입력이 단어/숙어인지 문장인지는 시스템이 자동 판별한다.

## Key Assumptions to Validate
- [ ] 사전/번역/TTS API 조합이 충분히 정확하고 아동 수준에 맞는 뜻·해석·발음을 제공한다 — 검증: 후보 API(무료 사전 API, 번역 API, Web Speech API 등) 몇 개로 실제 초등고학년~중학생용 단어/문장 테스트
- [ ] "뜻 입력 → 사전 API의 동의어 목록과 대조해 자동 채점" 방식이 실제로 정확하게 동작한다 — 검증: 다양한 표현으로 입력했을 때 오탐/누락 비율 확인
- [ ] 강제성 없는 순수 웹 앱이어도 아이가 복습카드를 반복 사용할 동기가 생긴다 — 검증: 며칠간 실사용 테스트

## MVP Scope
- 단어/숙어 검색 → 뜻 + 예문
- 문장 입력 → 한글 해석
- 단어/숙어/문장 발음 듣기(TTS)
- 검색한 단어/숙어 자동 저장(단어장), 해석한 문장 자동 저장(문장 노트) — 두 목록은 독립
- 저장된 문장 클릭 → AI 문법 설명 + 해석 + 발음
- 복습 퀴즈 모드 A: 단어 제시 → 뜻 입력 (사전 API 동의어 대조 자동 채점)
- 복습 퀴즈 모드 B: 뜻 제시 → 단어 입력
- 선택한 단어 리스트를 발음+뜻으로 읽어주기
- 단어장·문장 노트 항목은 개별 삭제하거나 전체 초기화하기 전까지 유지

## Not Doing (and Why)
- 문장의 복습 퀴즈화 — 문장은 문장 노트에 저장되고 클릭 시 문법 설명·해석·발음을 제공하지만, 양방향 복습 퀴즈 대상은 단어/숙어로 한정
- 여러 날에 걸친 장기 spaced repetition(간격 반복 알고리즘) — 1차는 "금일 학습" 단위 리뷰로 한정
- 부모용 대시보드, 여러 자녀/기기 지원 — 핵심 가치 검증 전에는 보류

## Open Questions
- 어떤 사전/번역/TTS/문법분석 API를 쓸 것인가 (무료 한도, 한국어 번역 품질, 아동 수준 적합성)
- 복습을 안 하거나 퀴즈를 틀렸을 때 후속 조치가 있는가, 아니면 순수 자발적 사용인가
