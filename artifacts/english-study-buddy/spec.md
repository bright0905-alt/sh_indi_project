# 영어 단어·숙어 학습 복습 웹앱 — spec

## 개요
자녀가 영어 단어/숙어/문장을 입력하면 시스템이 이를 자동으로 판별해 사전 검색(단어/숙어) 또는 한글 해석(문장)을 보여주고 발음을 들려준다. 검색한 단어/숙어는 단어장에, 해석한 문장은 별도의 문장 노트에 누적 저장된다. 단어/숙어는 사용자가 선택한 범위로 읽어주기와 양방향 복습 퀴즈를 할 수 있고, 저장된 문장은 클릭하면 적용된 문법 설명과 해석·발음을 다시 볼 수 있다.

## 범위

### 포함
- 입력한 문구가 단어/숙어인지 문장인지 시스템이 의미를 파악해 자동으로 판별
- 단어/숙어 검색 → 뜻 + 예문 표시, 단어장에 자동 추가(이미 있으면 검색 시각만 갱신)
- 문장 입력 → 한글 해석 표시, 문장 노트(단어장과 별도)에 자동 추가(이미 있으면 저장 시각만 갱신)
- 저장된 문장 클릭 → 적용된 문법 설명 + 한글 해석 + 발음 표시
- 자동 판별이 틀렸을 때 사용자가 수동으로 다른 유형으로 전환
- 입력한 단어/숙어/문장의 발음 듣기(영어 음성)
- 사전에 없거나 해석에 실패한 입력에 대한 안내 문구
- 단어장의 개별 삭제 및 전체 초기화
- 문장 노트의 개별 삭제 및 전체 초기화
- 단어장 항목 중 사용자가 선택한 항목만 대상으로 하는 읽어주기(발음 + 한글 뜻)
- 선택한 단어/숙어 대상 복습 퀴즈: 모드 A(단어 제시 → 뜻 입력), 모드 B(뜻 제시 → 단어 입력), 문제별 즉시 피드백

### 제외
- OS 레벨 다른 앱/URL 차단 — 웹 앱 구조와 근본적으로 충돌하여 idea 단계에서 제외 확정
- 문장의 퀴즈화 — 문장은 저장·문법 설명·발음까지 제공하되, 복습 퀴즈 대상에는 포함하지 않기로 확정 (퀴즈는 단어/숙어 전용)
- 여러 날에 걸친 간격 반복(spaced repetition) 알고리즘 — 대신 사용자가 매번 대상 범위를 직접 선택하는 방식으로 대체
- 로그인/계정, 여러 기기 간 동기화 — 단일 기기에서 로컬로 동작하는 것을 전제
- 부모용 대시보드/통계 — 핵심 가치 검증 전까지 보류

## 시나리오

### 1. 단어 검색
- **Given** — 입력창이 비어 있는 초기 화면
- **When** — 사용자가 "apple"을 입력하고 검색을 실행한다
- **Then** — 시스템이 단어로 판별하고 뜻과 예문을 표시하며, 단어장에 "apple"이 추가된다

성공 기준:
- [ ] "apple" 검색 → 뜻(예: "사과")과 예문 1개 이상이 화면에 표시된다
- [ ] 검색 후 단어장에 "apple" 항목이 나타난다

### 2. 숙어 검색
- **Given** — 입력창이 비어 있는 초기 화면
- **When** — 사용자가 "kick the bucket"을 입력하고 검색을 실행한다
- **Then** — 시스템이 숙어로 판별하고 뜻과 예문을 표시하며, 단어장에 추가한다

성공 기준:
- [ ] "kick the bucket" 검색 → 뜻과 예문이 화면에 표시된다
- [ ] 검색 후 단어장에 "kick the bucket" 항목이 나타난다

### 3. 문장 해석 및 저장
- **Given** — 입력창이 비어 있는 초기 화면
- **When** — 사용자가 "I go to school every day."를 입력하고 실행한다
- **Then** — 시스템이 문장으로 판별해 한글 해석을 표시하고, 문장 노트에 해당 문장을 추가하며, 단어장(단어/숙어 목록)에는 아무 것도 추가하지 않는다

성공 기준:
- [ ] 문장 입력 → 한글 해석 텍스트가 화면에 표시된다
- [ ] 문장 입력 후 문장 노트에 해당 문장 항목이 나타난다
- [ ] 문장 입력 전후로 단어장의 항목 수가 동일하다

### 4. 자동 판별 수동 전환
- **Given** — 입력한 문구가 단어/숙어 또는 문장 중 하나로 판별되어 결과가 표시된 화면
- **When** — 사용자가 "다른 방식으로 보기" 버튼을 클릭한다
- **Then** — 같은 입력 문구가 반대 유형으로 다시 처리되어 화면에 표시된다

성공 기준:
- [ ] 단어로 판별된 결과에서 전환 클릭 → 같은 문구의 문장 해석 결과가 표시된다
- [ ] 문장으로 판별된 결과에서 전환 클릭 → 같은 문구의 단어/숙어 사전 결과가 표시된다

### 5. 발음 듣기
- **Given** — 단어/숙어 검색 결과 또는 문장 해석 결과가 화면에 표시된 상태
- **When** — 사용자가 "발음 듣기" 버튼을 클릭한다
- **Then** — 입력한 문구가 영어 음성으로 재생된다

성공 기준:
- [ ] 단어 검색 결과에서 발음 듣기 클릭 → 해당 단어의 영어 음성이 재생된다
- [ ] 문장 해석 결과에서 발음 듣기 클릭 → 해당 문장의 영어 음성이 재생된다

### 6. 검색/해석 결과 없음
- **Given** — 입력창이 비어 있는 초기 화면
- **When** — 사용자가 사전에 없는 문자열(예: "asdkjqwe")을 입력하고 검색을 실행한다
- **Then** — "검색 결과가 없습니다" 안내 문구가 표시되고, 단어장과 문장 노트 어느 쪽도 변하지 않는다

성공 기준:
- [ ] 존재하지 않는 입력 → "검색 결과가 없습니다" 문구가 표시된다
- [ ] 해당 입력 전후로 단어장과 문장 노트의 항목 수가 각각 동일하다

### 7. 이미 저장된 단어 재검색
- **Given** — "apple"이 이미 단어장에 있는 상태
- **When** — 사용자가 "apple"을 다시 검색한다
- **Then** — 단어장의 "apple" 항목 개수는 늘지 않고, 해당 항목의 검색 시각만 갱신된다

성공 기준:
- [ ] "apple" 재검색 후에도 단어장의 "apple" 항목은 1개로 유지된다
- [ ] 재검색 후 "apple" 항목에 표시된 검색 시각이 갱신된다

### 8. 단어 개별 삭제
- **Given** — 단어장에 "apple" 항목이 있는 상태
- **When** — 사용자가 "apple" 항목의 삭제 버튼을 클릭한다
- **Then** — "apple" 항목이 단어장에서 즉시 사라진다

성공 기준:
- [ ] 삭제 클릭 → 단어장에서 "apple" 항목이 사라지고 항목 수가 1 감소한다

### 9. 단어장 전체 초기화
- **Given** — 단어장에 항목이 2개 이상 있는 상태
- **When** — 사용자가 단어장의 "전체 초기화" 버튼을 클릭하고 확인한다
- **Then** — 단어장의 모든 항목이 삭제되어 빈 목록 상태가 된다

성공 기준:
- [ ] 전체 초기화 확인 → 단어장 항목 수가 0이 되고 빈 상태 안내 문구가 표시된다
- [ ] 확인 대화상자에서 취소를 누르면 단어장이 그대로 유지된다

### 10. 선택한 단어 읽어주기
- **Given** — 단어장에 "apple", "kick the bucket" 2개 항목이 있는 상태
- **When** — 사용자가 "apple"만 체크하고 "읽어주기" 버튼을 클릭한다
- **Then** — "apple"의 영어 발음과 한글 뜻이 순서대로 음성으로 재생되고, 체크하지 않은 "kick the bucket"은 재생되지 않는다

성공 기준:
- [ ] "apple" 선택 후 읽어주기 → "apple" 발음과 뜻이 음성으로 재생된다
- [ ] 선택하지 않은 항목은 재생 대상에서 제외된다

### 11. 저장된 문장 클릭 → 문법 설명
- **Given** — 문장 노트에 "I go to school every day." 항목이 있는 상태
- **When** — 사용자가 문장 노트에서 해당 문장을 클릭한다
- **Then** — 원문, 적용된 문법 설명, 한글 해석, 발음 듣기 버튼이 함께 표시된다

성공 기준:
- [ ] 저장된 문장 클릭 → 해당 문장의 한글 해석 텍스트가 표시된다
- [ ] 저장된 문장 클릭 → 적용된 문법에 대한 설명 텍스트가 표시된다
- [ ] 상세 화면의 "발음 듣기" 클릭 → 해당 문장의 영어 음성이 재생된다

### 12. 문장 개별 삭제
- **Given** — 문장 노트에 "I go to school every day." 항목이 있는 상태
- **When** — 사용자가 해당 문장 항목의 삭제 버튼을 클릭한다
- **Then** — 해당 문장이 문장 노트에서 즉시 사라진다

성공 기준:
- [ ] 삭제 클릭 → 문장 노트에서 해당 문장이 사라지고 항목 수가 1 감소한다

### 13. 문장 노트 전체 초기화
- **Given** — 문장 노트에 항목이 2개 이상 있는 상태
- **When** — 사용자가 문장 노트의 "전체 초기화" 버튼을 클릭하고 확인한다
- **Then** — 문장 노트의 모든 항목이 삭제되어 빈 목록 상태가 된다

성공 기준:
- [ ] 전체 초기화 확인 → 문장 노트 항목 수가 0이 되고 빈 상태 안내 문구가 표시된다
- [ ] 확인 대화상자에서 취소를 누르면 문장 노트가 그대로 유지된다

### 14. 이미 저장된 문장 재입력
- **Given** — "I go to school every day."가 이미 문장 노트에 있는 상태
- **When** — 사용자가 같은 문장을 다시 입력하고 실행한다
- **Then** — 문장 노트의 해당 항목 개수는 늘지 않고, 저장 시각만 갱신된다

성공 기준:
- [ ] 같은 문장 재입력 후에도 문장 노트의 해당 항목은 1개로 유지된다
- [ ] 재입력 후 해당 항목에 표시된 저장 시각이 갱신된다

### 15. 복습 퀴즈 모드 A (단어 제시 → 뜻 입력)
- **Given** — 단어장에서 "apple"을 포함해 항목을 선택하고 퀴즈 모드 A를 시작한 상태
- **When** — "apple" 문제 화면에서 사용자가 뜻을 입력하고 제출한다
- **Then** — 제출 즉시 정답 여부와 올바른 뜻이 표시된 뒤 다음 문제로 넘어간다

성공 기준:
- [ ] "apple" 문제에 "사과" 입력 후 제출 → "정답" 표시와 올바른 뜻이 즉시 나타난다
- [ ] "apple" 문제에 오답(예: "자동차") 입력 후 제출 → "오답" 표시와 올바른 뜻이 즉시 나타난다

### 16. 복습 퀴즈 모드 B (뜻 제시 → 단어 입력)
- **Given** — 단어장에서 "apple"을 포함해 항목을 선택하고 퀴즈 모드 B를 시작한 상태
- **When** — "사과" 문제 화면에서 사용자가 단어를 입력하고 제출한다
- **Then** — 제출 즉시 정답 여부가 표시된 뒤 다음 문제로 넘어간다

성공 기준:
- [ ] "사과" 문제에 "apple" 입력 후 제출 → "정답" 표시가 즉시 나타난다
- [ ] "사과" 문제에 오답(예: "banana") 입력 후 제출 → "오답" 표시와 정답("apple")이 즉시 나타난다

## 불변 규칙

- 문장은 단어장(단어/숙어 목록)에는 추가되지 않고 문장 노트에만 저장된다. 단어장과 문장 노트는 서로 독립적이며, 한쪽의 삭제·초기화가 다른 쪽에 영향을 주지 않는다
- 복습 퀴즈와 읽어주기는 단어장 항목만을 대상으로 한다 — 문장은 대상이 되지 않는다
- 검색/해석 결과가 없는 입력은 단어장과 문장 노트 어느 쪽에도 어떤 변화도 일으키지 않는다
- 단어장과 문장 노트의 항목은 사용자가 개별 삭제하거나 전체 초기화하기 전까지, 새로고침이나 재방문 후에도 그대로 유지된다

## 의존성

- 단어/숙어의 뜻과 예문을 제공하는 사전 데이터 제공처에 대한 의존성
- 문장을 한글로 옮기는 번역 기능에 대한 의존성
- 문장에 적용된 문법을 분석해 설명을 생성하는 기능(AI)에 대한 의존성
- 입력 문구를 음성으로 재생하는 음성 합성 기능에 대한 의존성
- 입력 문구가 단어/숙어인지 문장인지 의미를 파악해 판별하는 기능에 대한 의존성
